# Focale organization profile

This repository contains the public GitHub configuration for the [Focale](https://github.com/focale-editor) organization.

- [`profile/README.md`](profile/README.md) is displayed on the organization's GitHub profile.
- Organization-wide community health files can also live here when needed.

Learn more at [focale-editor.app](https://focale-editor.app), or browse the organization's [public repositories](https://github.com/orgs/focale-editor/repositories).
